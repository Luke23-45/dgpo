# Baseline bring-up plan (iterate as needed)

## Phase 0 — Pre-flight (static checks; 5–10 min)

**Goal:** catch shape/range/type mismatches before any rollouts.

* **Action space contract**

  * Assert `env.action_space.shape == (A,)` and your BC/SB3 heads output `(B, A)`.
  * Log min/max action **after** squashing/clipping each step; expect values well inside limits (no permanent saturation).
* **Observation contract**

  * Images: `(C,H,W)` uint8 → normalized float32 `[0,1]` (or your model’s mean/std). Log per-channel mean/std for 256 random frames; expect non-zero variance.
  * Proprio: float32; log mean/std per field; no NaN/Inf; reasonable units (e.g., radians in ±3.2).
* **Seeding**

  * Fix seeds for env, numpy, torch; print them at start; run 2 resets → different states but reproducible across runs.

**Acceptance criteria**

* No asserts/NaNs; action/obs stats look sane (not all zeros, not saturated).

---

## Phase 1 — Actuator/Joints sanity (maps control to motion; 2–3 min)

**Goal:** prove each action dimension actually moves the intended joint and the gripper.

* **One-hot nudge test**

  * From a mid-range pose, for each action dim `i`:

    * Apply `+ε` for 10 steps, record Δqpos; reset; apply `−ε` for 10 steps, record Δqpos.
  * Build a **response matrix** `R[i, j] = sign(Δqpos_j)` and report magnitude.
* **Gripper**

  * Open/close test: apply max open for 20 steps → width increases; max close → decreases.

**Acceptance criteria**

* `R` is **mostly diagonal** with expected signs; gripper responds; no joint stuck (|Δ| ≈ 0).

---

## Phase 2 — Observation pipeline sanity (vision + proprio to model; 2–3 min)

**Goal:** verify the tensors the policy sees are correct.

* Tap the policy’s `forward()` once per reset:

  * Check dtypes (float32 for everything fed into nets).
  * Log image channel means/std; verify gradients flow (one backward on dummy loss; grad norms > 0).
  * If using OCTO embeddings, log embedding L2 norm & variance across 64 frames (non-zero, not exploding).

**Acceptance criteria**

* Dtypes float32; non-zero grad norms; embedding stats stable (not NaN/Inf, not \~0).

---

## Phase 3 — Reward sanity (scripted & random baselines; 5–10 min)

**Goal:** ensure the reward encodes the task and responds to progress.

* **Scripted heuristic** (even a crude “move toward goal”):

  * Run 10 episodes; expect strictly higher mean return than random.
* **Monotonic shaping check**

  * For a trajectory, correlate step-wise reward with a proxy (e.g., −distance\_to\_goal); expect Pearson r > 0.5.
* **Terminal signals**

  * Count `done` reasons (success, timeout, failure). Success must be reachable by the scripted policy (≥ 10–30%).

**Acceptance criteria**

* Scripted > random returns; shaping correlation positive; success isn’t unreachable.

---

## Phase 4 — Learning smoke tests (short runs; 3–5k env steps; ≤15 min)

**Goal:** prove the agent can learn *at all*.

* **BC-only micro-fit (if using IL)**

  * Train on 512 samples for 1–2 epochs; expect supervised loss ↓ (≥30–50%).
* **PPO/On-policy**

  * Tiny nets (avoid overfitting time): e.g., 2×64 MLP head.
  * Run \~3–5k steps with entropy coeff > 0 initially.
  * Track: episodic return (EMA), value loss, policy loss, entropy, KL, success rate, action magnitude.

**Acceptance criteria (quantitative)**

* **Return slope** positive over last 60% of steps (fit a line; slope > small ε).
* Entropy **decreases slightly**; KL not exploding (e.g., ≤0.02 per update unless you configure otherwise).
* Value loss not diverging; no persistent action saturation.

## Phase 5 — Instrumentation you keep on (always-on debug)

**What to log (every N updates / episodes):**

* **Obs stats:** image mean/std, proprio mean/std.
* **Action stats:** min/max/mean; % at clamp limits.
* **Losses:** policy, value, entropy, KL, grad-norm, param-norm.
* **Reward components:** each term separately (helps triage).
* **Success/length:** success rate, avg episode length.
* **Videos:** 5–10 episodes every K steps (overlay text: reward, success, action clamp %).

Use TensorBoard/W\&B; save JSONL with aggregates to enable quick slope checks.

## Minimal helper snippets (drop-in)

**Actuation probe wrapper (env-agnostic):**

```python
class ActuationProbe:
    def __init__(self, env, eps=0.2, steps=10):
        self.env, self.eps, self.steps = env, eps, steps
    def response_matrix(self):
        import numpy as np
        A = self.env.action_space.shape[0]
        R = np.zeros((A, A))
        base = self.env.reset()
        q0 = self.env.sim.data.qpos.copy()  # adapt accessor for your env
        for i in range(A):
            for sgn in (+1, -1):
                self.env.reset()
                self.env.set_state(q0)      # adapt for your env
                a = np.zeros(A); a[i] = sgn*self.eps
                for _ in range(self.steps):
                    self.env.step(a)
                q1 = self.env.sim.data.qpos.copy()
                delta = (q1 - q0)
                R[i] += np.sign(delta[:A]) * 0.5  # average over +/-
        return R
```

**Return-slope quick check:**

```python
def slope(xs, ys):
    import numpy as np
    xs = np.asarray(xs); ys = np.asarray(ys)
    xs = (xs - xs.mean())/xs.std()
    b = np.polyfit(xs, ys, 1)[0]
    return float(b)
```

**Obs stats hook (attach in your vectorized env or callback):**

```python
class ObsStats:
    def __init__(self): self.n=0; self.sum=0; self.sq=0
    def update(self, x):
        import numpy as np
        x = x.astype(np.float32).ravel()
        self.n += x.size; self.sum += x.sum(); self.sq += (x*x).sum()
    def mean_std(self):
        import numpy as np
        m = self.sum/self.n; v = self.sq/self.n - m*m
        return m, max(v, 1e-12)**0.5
```

## Triage guide (if something fails)

* **No joint moves / wrong joint moves:** check action scaling, sim control mode (position/velocity/torque), and the action→joint mapping. The response matrix will tell you which indices are crossed.
* **Actions saturated:** reduce action std/init, tighten clip, or rescale env action space; verify the policy’s squashing (tanh) vs env bounds.
* **No learning but rewards stable:** increase entropy coeff early, ensure advantages are normalized, reward magnitude roughly \~1; verify time-limit truncation handling.
* **Exploding/NaN:** lower LR, clip grads, check reward spikes (cap), inspect observation NaNs (log and mask).
* **Scripted policy not better than random:** reward shaping likely broken or sensors mis-wired.
